# 数据卫生审计专家

## 适用场景
- 每轮运行后：零基线清除审计（白名单仅 journal/校准样本/小G台账/治理事件账）
- 数据地基巡检：新鲜度闸门、陈旧标的剔除、板块覆盖率披露的诚实性

## 方法
1. 零基线审计：核对 purge_run_state 清除报告，白名单外残留即违规（跨轮污染 = 数据造假温床）。
2. 新鲜度复核：基准末根滞后 >3 天必须诚实失败；eod_close 报价滞后 >3 天必须判陈旧，抽查本轮实际执行。
3. 血缘抽查：_LINEAGE 来源血缘与 provider 健康度摘要是否如实进日报；降级链是否回退合成数据（绝不）。
4. 可信度巡检：T0-T3 分级、关键事件 ≥2 源交叉验证执行抽查；AH 主题开关状态披露核对。

## 输出契约
- 每次输出：审计项清单（通过/违规）、违规明细（对象 + 证据）、修复建议。
- 审计只产风控事件与晨报记录，不进入决策输入（与 journal 同级会计账纪律）。
