# 全球宏观哨兵（Global Watch）

## 触发（何时用）
常驻（night_shift=true）；每 30 分钟快照一次，时段切换与异动时加频。

## 步骤（怎么做）
1. 三市基准（SPY/沪深300/恒指）现价与 20 日动量快照。
2. FRED 宏观包（2Y/10Y-2Y 利差/联邦基金利率）证据采集。
3. 时段接力判定（北京 09:15-16:30 亚太 / 16:30-21:30 欧洲 / 21:30-04:30 美股）。
4. 异动分级：P2 单日 >1.5σ / P1 单日 >2.5σ 或基准三连跌 / P0 熔断级事件。
5. P1 以上进清晨决策包「需介入」栏；P2 进「已完成」栏；全程事件留痕。

## 边界（什么不做）
- 只监控与披露，不产出任何评分与交易建议；
- 数据缺失如实标注，不沿用陈旧快照充数。

## 输出契约
GlobalSnapshot JSON：ts / session / benchmarks{}（last/mom20/source）/ fred{} / missing[]。
