# 多市场官网与综合资产管理设计（MULTI_MARKET）

> 背景：官网原为美股单市场设计。三市（美/A/港）落地后，官网演进为两层结构，
> 并为"单一市场投资 → 多元市场综合资产管理"的演进定调。

## 一、为什么不能只做"三个孤立的官网"

三个市场的**决策口径必须分开**（A股 T+1/涨跌停、港股 VCM/半日市、美股 PDT/熔断，MRS 基准组各不相同），但**风险必须合并**——投资者的真实敞口是"三市持仓的总和"，不是三个独立账户。分开看会漏掉两件最重要的事：

1. **总风险预算**：美股 MRS\*=8（黄金共振满仓 90%）+ A股 MRS\*=8 + 港股 MRS\*=8 同时发生时，三市各自按本地上限开仓，组合实际敞口可能是净值的 2.7 倍——单市场视角永远看不见。
2. **对冲价值**：三市相关性低（A股与美股历史相关约 0.3–0.5），低相关的持仓组合本身就是天然对冲——但这是组合层的结论，不是任何单一市场能给出的。

## 二、官网两层架构（v3.4 已实现）

```
组合总览（组合层 · 默认首页）
 ├─ 三市状态卡：MRS* / 五态行动 / 仓位上限 / 覆盖 / 通道（验证期）
 ├─ 组合净值与配置：三市模拟盘净值汇总 + 市场间配置占比条
 ├─ 统一风险预算：组合 Gross Cap = min(Σ市值, 组合上限)（v1 口径见 §三）
 └─ 跨市场注记：相关性/对冲/货币风险的口径披露
├─ 美股页签（完整日报，原有口径不变）
├─ A股页签（T+1/涨跌停/轻仓验证期标识）
└─ 港股页签（T+0/VCM/轻仓验证期标识）
```

实现：`scripts/build_site.py` 读取三市最新 `result_*.json` + `sim_portfolio.json`，
生成 `site/index.html`（组合总览）+ `site/us.html` / `site/cn.html` / `site/hk.html`
（各市场日报原样分发，零外部依赖纪律不变）。`scripts/publish_site.sh` 已接入。

## 三、组合层风险预算（v1 口径，已在总览页披露）

| 规则 | 口径 | 依据 |
|---|---|---|
| 组合总仓位上限 | `min(Σ 各市场市值, 组合 Gross Cap)`；组合 Gross Cap 默认 90%（config 单一口径，客户 patch 只可加严） | 防三市共振日叠加敞口 |
| 单市场额度 | 各市场 MRS\* 档位上限（白皮书附录 B，不变） | 框架不变 |
| 分配顺序 | 各市场 TOS 排序分加权，组合层截断时按 TOS 从高到低放行 | 强者优先 |
| 验证期市场 | 轻仓通道（×0.3–0.4）额度独立计算，不占标准额度 | D7 诚实纪律 |

> 诚实边界：组合层当前是**披露与预算层**（看得见、有上限），
> 自动再平衡与主动对冲指令是下一阶段（见 §五演进路线），
> 当前不产生任何跨市场交易动作。

## 四、跨市场对冲的设计（演进方向，当前为披露口径）

1. **自然对冲（已具备）**：三市低相关持仓组合 + 各市场独立的止损纪律——这是"免费的"对冲，组合总览页把它的价值显性化（分市场回撤 vs 组合回撤对比）。
2. **指数对冲（下一阶段）**：当组合层识别到系统性风险（如三市 MRS\* 同时跌破 4），用指数 ETF/期货做对冲而非清仓——工具：美股 SPY 看跌/ES 期货、A股 股指期货（IH/IF/IC，需期货账户）、港股 HSI 期货。合规前置：衍生品权限与适当性。
3. **货币风险（披露口径）**：A股 CNY / 港股 HKD（联系汇率锚定 USD）/ 美股 USD。HKD 风险极小，CNY 是真实变量——总览页以 USD 与本地币双口径列示净值，货币波动单列披露，不做汇兑对冲建议（个人投资者通常无工具）。
4. **中央簿记借鉴（Citadel Central Book）**：复盘层统计各市场/各角色的近期胜率，**优胜市场/策略的信号权重可被组合层放大**——与策略优化师的 WFA 提案共用审批流（人裁决）。

## 五、演进路线

| 阶段 | 内容 | 状态 |
|---|---|---|
| M1 多市场视图 | 组合总览 + 三市页签（本设计） | ✅ 已落地 |
| M2 统一风险预算执行 | 组合层截断真实生效（L4 放行前过组合闸门） | 下一阶段 |
| M3 跨市场归因 | 归因到市场/币种/对冲贡献三层（诸葛团队扩展） | 下一阶段 |
| M4 主动对冲 | 指数对冲工具接入（合规前置）+ 中央簿记权重调节 | 设计储备 |

## 六、纪律继承（不因多市场而松动）

- 白皮书十条铁律**逐市场**生效（MRS 闸门、1R、止损、DSR 各自独立）；
- 组合层只加**上限与披露**，不加**分数与预测**（组合层没有自己的"观点"，只有预算）；
- 各市场诚实失败独立：单市场数据全断只影响本市场页签，组合总览如实标注"本市场当日无有效数据"。
