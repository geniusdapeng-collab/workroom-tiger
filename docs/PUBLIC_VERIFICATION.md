# 公开验证章程（Public Verification Charter）

小G模拟盘面向全球实时直播。本章程明确直播的定位、风控边界、宣传纪律与统计显著性检查机制，是系统对外口径的唯一准则。

## 一、定位：这不是荐股直播间，是一场全程留痕的公开实验

- 直播页面承诺的是**纪律与透明度**，不是胜率。
- 实验问题只有一个：一套全 AI 决策的系统，能不能在真实市场里长期活下去。
- 验证方式：信号次日开盘价成交（无未来函数）、逐笔记账、赚亏如实公示。

## 二、风控边界：最坏情况亏多少，是设计出来的

| 边界 | 规则 | 含义 |
|---|---|---|
| 单笔最大风险 | 账户净值 0.8% | 股数由止损距离反推，任何一笔打止损最多失血 0.8% |
| 单票仓位上限 | 净值 20% | 再看好也不一把梭 |
| 环境闸门 | 市场环境评分跌破警戒线 | 禁止开新仓，空仓也是一种仓位 |
| 成交纪律 | T+1 开盘价 | 无未来函数，同日重跑幂等不重复成交 |
| 时间止损 | 7 个交易日未推进 | 资金不为横盘站岗 |
| 盈利保护 | 浮盈 ≥ 2R | 止损上移至成本线，亏钱的交易不回头 |

最坏情景测算：满仓 8 只同日均触发止损，组合单日理论失血约 6.4%；遇跳空缺口按开盘价执行止损，滑点会放大实际亏损，极端交易日失血上界约 8%–10%。这个数字敢公开，因为它有设计上限——不存在爆仓式结局。

## 三、宣传纪律

- 累计已结算交易未满 100 笔前：页面与一切对外传播不引用胜率、期望值作为有效性结论，仅作过程快照并标注"样本积累中，不作结论"。
- DSR 显著性检验未通过前：不对外宣称"策略有效"、"AI 能炒股"。
- 亏损交易日照常更新页面与台账，禁止粉饰、删账、选择性展示。
- 核心机密（公式、权重、阈值、内部排序分）不出报告、不出直播页。

## 四、统计显著性检查点（DSR）

- 首个检查点：**2026-10-30 前后**（届时约 60+ 个交易日真实样本）。
- 方法：以累计真实样本重跑滚动前推（WFA）调参检验，按 Deflated Sharpe Ratio 判定——DSR ≥ 0.5 视为统计显著。
- 通过：对外传播可引用统计结论，页面摘除"样本积累中"标注。
- 未通过：结论照实公开，回炉理论层修正，页面加注说明——失败同样是实验数据。

## 五、样本积累机制（系统内建）

- `reports/sim_portfolio.json`：小G模拟盘台账，跨轮累计，绝不手动清零。
- `reports/options_hist/`：期权快照历史库，逐日按日落账，积累 ≥10 条后分位数生效。
- 上述台账每轮随仓库提交持久化，是跨轮累计的唯一通道；`cache/` 已被忽略机制排除，不承担样本积累职责。
