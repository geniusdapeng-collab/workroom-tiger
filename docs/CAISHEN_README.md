## 架构（v5.0 全链路，17 个注册环节逐一点名）

```
SearchHub 搜索集成   6 源并发 + TTL缓存 + 墙钟 + 熔断                    ★v5.0
  ├ 横向: agent-gw 全网搜索 · Google News · Reddit（多语言/小众论坛）
  └ 纵向: SEC EDGAR(8-K供应链) · PatentsView(专利) · FederalRegister(政策微调)
  ↓
数据清洗            规则仅去重/格式校验；消歧/情感/事件/关联 全 LLM      ★v5.0
  ↓
科技股专项子集群    监测·全球联动(三星/海力士/台积电)·舆情·风险·融合     ★v5.0
  ↓                → TechChainSignal（景气度/预警/传导图）标准接口
  ↓
NarrativeAgent     SHS 叙事维度 LLM 化（EPS修正×指引语气）              ★v5.0
  ↓
数据层 providers → Layer0 扫描 → L1 MRS → L2 SHS → L2b ICS → L3 TSS → L4 风控
  ↓
日报（科技链章节 + 红线执行轨迹披露 + 胜率追踪）
  ↓
journal 落账结算 → WFA+DSR 调参 → tuned_params 次日生效
```

**红线三原则（机器强制执行，非文档承诺）**：
1. 全链路 17 环节 `ExecutionTracer` 逐一点名，缺一个即抛 `RedlineViolation` 停止运行；
2. LLM 环节（清洗语义/链舆情/链风险/板块叙事）由 `llm_guard` 把守——
   要么 LLM 真实产出，要么 `Passthrough` 透传原始数据，**没有规则回退这条路**；
3. 环节无产出 → 透传兜底 + WARNING 日志，日报第十节逐环节披露 ✅/🔁 与原因。

**缺失因子再归一化（v4.1 核心校准）**：任何子维度缺数据时传 `None`，
聚合层将其剔除并按剩余权重重新归一化——不再钉向中性 5 分而暗中收紧闸门。
修复前免费数据下 SHS 主线池 0 天（叙事/微观钉 5 分使 SHS 上限 ≈6.5，永远够不到 7.5）；
修复后主线池 126/204 天，闸门恢复理论设计的选择性。

## 快速开始

```bash
pip install -r requirements.txt

# 离线演示（无需网络，结果确定可复现；含搜索/科技链全链路）
python3 main.py --demo

# 全市场真实扫描（纽交所+纳斯达克官方清单 + 实时搜索 + LLM 语义，需网络）
python3 main.py --universe full --top 30 --picks 8 --account 100000

# 盘前作战计划 / 盘中触发器
python3 main.py --mode premarket --demo
python3 main.py --mode intraday --demo --interval 60 --cycles 10

# 无未来函数回测（帧自动缓存，二次运行秒级）
python3 main.py --demo --backtest --bt-days 380

# 滚动 WFA 调参 + DSR 校正（真实数据建议 --bt-days 560 以上）
python3 main.py --demo --backtest --tune --bt-days 560

# 运行测试
python3 -m pytest tests/ -q        # 148 项
```

LLM 配置：语义环节通过 agent-gw SDK 调 Kimi `chat_completion`
（`~/.kimi/agent-gw.json` 或 `KIMI_API_KEY`；模型可用 `KIMI_CHAT_MODEL` 覆盖）。
**key 无权限/网络失败时系统不会退回规则引擎**——对应环节按红线透传并在日报标注，
你的有权限 key 到位后语义评分自动启用，无需改任何代码。

参数：`--mode daily|premarket|intraday` `--universe core|extended|full|file:清单`
`--provider yahoo|stooq|demo` `--out 报告路径` `--quiet 只输出JSON摘要`

## 自我迭代闭环（v4.1）

1. **落账**：每日放行信号写入 `reports/journal.json`（去重，含入场/止损/模板快照）；
2. **结算**：次日按与回测完全相同的规则结算（止损优先、2R 保护、时间止损）；
3. **追踪**：日报第九节输出累计/近 20/近 50 胜率、期望值、分模板表现；
4. **调参**：`--tune` 跑滚动 WFA（train 126 / test 63 / step 63，27 组闸门网格），
   折外（OOS）汇总后做 DSR 多重检验校正；**DSR 不显著则保持理论默认参数**——
   demo 随机数据上 DSR=0.000 正确拒绝了过拟合；
5. **生效**：通过校正的参数写入 `tuned_params.json`，次日运行自动覆盖闸门并留痕。
