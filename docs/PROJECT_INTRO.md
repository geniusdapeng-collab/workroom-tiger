# 老虎全球资产管理（Tiger Global Asset Management）项目介绍

> 一句话：以财神爷 AI 炒股系统为交易内核、以 WorkLoom IM 为治理外壳的
> 全自动化模拟盘交易系统——覆盖美股 / A股 / 港股，24 小时运行。
> **No prediction. Process, discipline, audit.**

**当前阶段：仅模拟盘（paper trading）。不构成投资建议，不承诺收益。**

## 一、项目缘起：从财神爷到老虎全球资产管理

项目起点是[财神爷 AI 炒股系统](CAISHEN_README.md)：一个严格遵循
[《AI 短线美股交易（1–15 天波段版）白皮书》](../reports/AI短线美股交易白皮书_20260730.pdf)
的多 Agent 交易系统——MRS（市场共振）→ SHS（板块热度）→ ICS（产业链周期）
→ TSS（建仓评分）→ 风控闸门的六层决策栈，配合信号日记（journal）、
无未来函数回测、滚动 WFA 调参与 DSR 多重检验校正，形成"信号可结算、
胜率可验证、参数可迭代"的闭环。

财神爷解决了"怎么交易"的问题，但没有解决"怎么治理"的问题：
每个交易动作谁负责、白皮书红线有没有第二道机器保险、复盘结论如何沉淀。
为此我们做了两份调研，结论直接决定了老虎交易的形态：

### 调研一：行业标杆竞品深度调研（[research/01_benchmark](../research/01_benchmark.html)）

对桥水 AIA 等 9 家行业标杆的深度拆解，三个可直接吸收的亮点：
- **多空辩论证据层**（桥水 AIA 辩论制）：对灰区标的引入 Bull/Bear/Coordinator
  三方辩论，产出交易卡片"第六段"证据——只进报告，绝不改分（S2 已落地）；
- **统计校准层 + 样本门槛**：信号分数 → 实际结果的校准摘要，样本 <50 只输出
  Wilson 区间表述，日报固定披露"校准样本积累中（n/50）"（S2 已落地）；
- **摩擦成本三栏**：模拟盘账本分毛/净/摩擦三栏，滑点按 ADV 分档（S2 已落地）。

### 调研二：投资团队一线作业与 know-how（[research/02_frontline](../research/02_frontline.html)）

对真实投资团队作业流的调研，结论是**数据地基与治理留痕比模型聪明更重要**：
- 数据卫生纪律（多源交叉验证、可信度分级、时效性闸门）必须先于一切评分（S3 已落地）；
- 每个动作要可追责：五元事件（Who×Context×Object×Decision×RuleImpact）+ 哈希链；
- 复盘要成机制：只复盘流程不复盘运气，违规六条必标记（附录D 口径）。

两份调研合并为[升级方案 v3](../research/UPGRADE_PLAN_v3.md)（财神爷主体版，
已确认）：**内核零改写，外壳做治理**。

## 二、架构详解：内核 + 外壳 + 角色包

```
┌──────────── WorkLoom IM 治理外壳（governance/，TypeScript）────────────┐
│ 五元事件库(哈希链留痕) · 围栏引擎(白皮书阈值→block级基线) · Quest 编排    │
│ night-shift 夜间守夜 · 审批卡片 · 组织记忆 · site 官网(责任界面)          │
│ ┌────────── 财神爷交易内核（仓库根目录，Python，完整保留）──────────────┐ │
│ │ 21 环节管线（红线点名，缺一即事故）                                    │ │
│ │ 六层决策栈：L0 全市场扫描 → L1 MRS → L2 SHS → L2b ICS → L3 TSS → L4 风控 │ │
│ │ SearchHub 6 源情报 · 七环行情降级链 · 零基线纪律（每轮从零开始）        │ │
│ │ 信号日记 journal → 校准层 → WFA+DSR 迭代 · 小G 模拟盘（$100,000）      │ │
│ │ 复盘闭环（诸葛团队）：日度归因/周度体检/月度 WFA 提案 + 三手势审批      │ │
│ └──────────────────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────────────┘
```

### 交易内核（仓库根目录，Python）

- **single source of truth**：所有权重/阈值/档位集中在 `trading_system/config.py`；
- **21 环节管线**：`trading_system/redline/` 注册表即契约，ExecutionTracer
  逐环节点名，缺环节立即抛 RedlineViolation（系统性事故）；LLM 环节不可逆
  （只允许透传兜底，绝不存在规则回退分支）；
- **零基线纪律**：每轮运行清除上一轮残留（搜索缓存/全市场清单/回测帧缓存），
  白名单仅保留会计台账（journal / sim_portfolio / 校准样本 / 治理事件账）；
- **工程测试**：252 项 pytest 全绿，含静态审查（防改分路径、防决策链漂移）。

### 治理外壳（governance/，TypeScript，WorkLoom IM 底座快照）

- **只做治理不做决策**：不产出任何交易评分，负责把交易动作变成可追责事件；
- **五元事件 + 哈希链**：内核 → 外壳桥接（`trading_system/governance_bridge.py`，
  S5），pipeline 每环节、L4 闸门、模拟盘成交、合规命中全部留痕，
  SHA-256 链可验真（防篡改）；
- **围栏三层结构**：基线层（block 不可改，R-T1~R-T15 从 config 生成，
  `scripts/gen_fences.py`）/ 客户 patch 层（review 只许收紧）/ 策略快照层。

### 行业角色包（governance/bundles/trading/）

六装配槽（对齐 WorkLoom bundles 规范）：档案 Schema、对象与阶段枚举
（对象 8 类、阶段 5 个：观察期/模拟盘/小额实盘/扩量期/回撤管制期）、
工具集、围栏包、Agent presets（财神爷 20 个 Agent 原职责包装 + 辩论组/
校准官/数据质量官/合规官 + 复盘条线 4 个数字员工）、工作台 UI。

## 三、三市支持（S4：框架不变、输入替换）

同一套六层决策栈覆盖三个市场，差异全部参数化在 `config.py` 与
`trading_system/markets/`：

| 市场 | 基准组 | 板块代理 | 特殊规则 |
|---|---|---|---|
| 美股 US | SPY / TNX / VIX / VIX9D | 12 只板块 ETF | 现状行为（基准缺失诚实失败） |
| A股 CN | 沪深300 / 中债10Y / 50ETF波指 | 中证 800 行业指数 | 涨跌停 ±10%/±20%/±5%；交易日历内置 |
| 港股 HK | 恒生指数 / 美债10Y / 恒指波指 | 恒生行业指数 | VCM 冷静期标的集合；半日市日历 |

纪律：D1 框架不变（阈值结构不动，只替换输入）；D2 不可得维度记缺失走
"剔除再归一化"，绝不编造；D7 新市场先轻仓，满 50 笔结算且 DSR 过关才毕业。

## 四、复盘优化机制（S6：数字负责人=诸葛团队）

复盘条线 4 个数字员工（`trading_system/review/`）：

| 角色 | 模块 | 职责 |
|---|---|---|
| 归因分析师 | `attribution.py` | 日度逐笔归因（信号来源层/入场质量/出场类型/市场环境快照）+ 违规六条自动检测（附录D：MRS不允许却开仓/非主线交易/禁追高条件下追高/财报前未降仓/触发止损不执行/≥2R未保护），命中即标记并计数 |
| 统计员 | `weekly.py` | 周度统计体检：累计/近20/近50 胜率、期望R、分模板、R 分布、校准样本 n/50 联动；三档结论（符合预期/关注/告警，阈值进 config） |
| 策略优化师 | `monthly.py` | 月度 WFA 提案：DSR 不显著自动 reject（D7 迭代诚实），显著才 pending_review；**只提案不生效** |
| 诸葛（复盘主持） | `chief.py` | 编排日/周/月三频率，产出复盘纪要 `reports/复盘_<日期>.md`，纪要进治理五元事件 |

审批流（对齐 WorkLoom 三手势）：
- `python3 main.py --review-list` 查看提案；
- `--review-approve <id>` → 状态 approved，写 `tuned_params.json`
  （effective_from=次日），复用 `--use-tuned` 纪律：默认不加载，显式启用，
  生效动作写日报披露 + 治理事件；**次日生效**由 `apply_tuned_params` 机器执行；
- `--review-reject <id> --reason "..."` → 驳回原因必填，样本回流组织记忆；
- 模拟盘阶段审批不阻塞 pipeline 运行（只影响参数提案生效）。

红线：复盘产物属会计账白名单（D5），只进报告层与治理事件，绝不进入决策输入
（pytest 静态审查锁定）；只复盘流程不复盘运气。

## 五、合规与边界

- **仅模拟盘**：系统不做真实下单；小G 模拟盘（初始 $100,000，T+1 开盘价成交，
  无未来函数）是公开验证的载体（赚亏如实、禁止粉饰，D8）；
- **不构成投资建议**：本系统为技术研究与模拟验证项目；
- **数据边界**：免费行情源存在延时（报告中如实标注）；生产链路绝不回退合成数据；
- **实盘前置条件**：需另行接入持牌券商并满足各市场监管要求
  （美股 SEC 15c3-5、A股程序化交易报备、港股 SFC），且 review 级围栏启用阻塞式审批。
