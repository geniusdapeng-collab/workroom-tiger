# 财神爷AI炒股系统 · 投资者网站（site/）

本目录是系统对外的**投资者网站**完整产物，与交易系统主体代码同仓维护、同版本演进。

## 构成总览

| 层 | 位置 | 说明 |
|---|---|---|
| 网站前端 | `site/index.html` | 自包含单文件 HTML：全部样式、脚本、SVG 图表、AI 生成配图（base64 内嵌）都在一个文件里，零外部依赖，双击即开、可直接托管到任意静态托管。内含「📊 策略验证中心」页签：策略成绩单（净值 vs QQQ/SPY、R 分布、月度热力）、信号全生命周期档案卡、盈亏归因实验室（六维切片 + 失败模式红牌）、全量台账——回溯系统的证明/诊断/进化三层全部公开 |
| 前端生成器 | `trading_system/report_html.py` | 网站的"模板引擎"：把一轮全链路结果渲染成上面的单文件网站（双页签：决策日报 / 小G模拟盘，含历史回溯与交易理念页） |
| 网站配图资产 | `trading_system/hero_art.py` | 黑金财神头图与产业链主题插图的 base64 资产，前端构建期内嵌 |
| 后端链路 | `main.py` + `trading_system/` | 网站数据的"后端接口"：情报采集（6 源搜索）→ AI 语义清洗 → 科技股产业链子集群 → 市场环境 × 板块 × 产业链 × 个股四层共振 → 风控闸门 → 信号落账结算，产出的 `PipelineResult` 即网站的全部数据源 |
| 定时调度 | 云端 cron（盘后 / 盘前） | 每个交易日自动跑全链路，用真实数据重新生成 `site/index.html` 并发布 |
| 理论白皮书 | `site/AI短线美股交易白皮书_20260730.pdf` | 系统方法论完整文档，供下载阅读 |

## 数据流（后端 → 前端）

```
trading_system/ 全链路（17 个注册环节）
      │  PipelineResult（市场环境/板块/产业链/观察名单/决策/动作）
      ▼
report_html.render_html()  ── 生成 ──▶  reports/日报_YYYYMMDD.html
      │                                       │ 同步
      ▼                                       ▼
  投资者网站                          site/index.html（本目录，随仓发布）
```

## 本地重新生成网站

```bash
python3 main.py --demo          # 离线合成演示数据（数据栏如实标注）
python3 main.py                 # 真实全链路（需行情与搜索通道凭证）
cp reports/日报_$(date +%Y%m%d).html site/index.html
```

## 纪律

- **自包含**：`index.html` 不允许引用任何外部脚本/样式/图片（测试套件有断言守护）。
- **数据诚实**：演示数据必须在数据源栏明确标注"离线合成演示数据"；真实运行如实披露行情血缘与降级轨迹。
- **投资者脱敏**：网站只呈现业务语言结论，不暴露内部公式、权重与阈值。
